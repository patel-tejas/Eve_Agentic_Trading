# Plans

Implementation plans for this repo live here, one file per plan, named
`YYYY-MM-DD-short-slug.md`. Each plan should carry a `Status` note near
the top that's kept current as work progresses (not implemented /
in progress / done / superseded), and should point at
`plans/PROGRESS.md` for the detailed implementation log rather than
duplicating it.
